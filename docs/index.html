이 기기용

TrackpadRemote

iPhone · iOS 17 이상

트랙패드가 되는 쪽. 터치를 읽어 Mac으로 보냅니다.

  • 클릭, 스크롤, 핀치 확대, 세·네 손가락 제스처
  • IP 입력 없이 근처 Mac을 자동으로 찾음
App Store에서 받기
이 기기용

TrackpadServer

Mac · macOS 14 이상

커서를 움직이는 쪽. 메뉴 막대에서 iPhone을 기다립니다.

  • Dock 아이콘 없이 메뉴 막대에만 뜸
  • 커서를 움직이려면 손쉬운 사용(접근성) 권한이 필요해, Mac App Store가 아니라 여기서 배포합니다
Mac용 다운로드

연결하는 법

  1. Mac에서 TrackpadServer를 실행합니다. 메뉴 막대에 아이콘이 생깁니다.
  2. iPhone에서 TrackpadRemote를 실행하고 로컬 네트워크 접근을 허용합니다.
  3. 두 기기 모두 Wi‑Fi와 Bluetooth가 켜져 있으면 자동으로 연결됩니다.
  4. 처음 연결될 때 Mac이 손쉬운 사용 권한을 묻습니다. 허용해야 커서가 움직입니다.

잘 안 되면 지원 페이지를 보세요.
